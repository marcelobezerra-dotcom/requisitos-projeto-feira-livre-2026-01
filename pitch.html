Modernizando a administração das feiras livres de Fortaleza

Problema

Desafios Atuais

As feiras livres de Fortaleza enfrentam significativos desafios operacionais devido à falta de um sistema de gestão integrado:

📋 Controle Manual

Processamento de cadastros de feirantes realizado manualmente, propenso a erros e inconsistências.

💼 Falta de Organização

Dificuldade em gerenciar barracas, coordenar feirantes e manter histórico de alterações.

💰 Gestão de Taxas Complexa

Acompanhamento inadequado de pagamentos e débitos de feirantes participantes.

🔍 Fiscalização Ineficiente

Fiscais não dispõem de ferramentas para consultar rapidamente a situação dos feirantes.

📊 Falta de Relatórios

Impossibilidade de gerar relatórios para análise de arrecadação e desempenho das feiras.

🚫 Fraudes e Irregularidades

Alto risco de fraudes e participações não autorizadas sem rastreabilidade.

Impacto: A falta de um sistema integrado resulta em ineficiência administrativa, risco de fraudes, redução de receita e baixa qualidade no atendimento ao cidadão.

Público-alvo

Personas Principais

👨‍💼 Gestor da Secretaria Municipal

Responsabilidade: Gerenciar feiras, cadastros, licenças e relatórios.

Necessidade: Sistema integrado para controlar todas as operações das feiras, aprovar cadastros e gerar insights para tomada de decisão.

Prioridade Alta

👨‍🏭 Feirante

Responsabilidade: Solicitar licença, pagar taxas e participar das feiras.

Necessidade: Interface simples para solicitar autorizações, acompanhar pagamentos e consultar informações sobre feiras.

Prioridade Alta

👮 Fiscal Municipal

Responsabilidade: Fiscalizar barracas e verificar regularidade dos feirantes.

Necessidade: Acesso rápido a dados de feirantes autorizados e ferramenta para registrar ocorrências.

Prioridade Alta

👤 Cidadão

Responsabilidade: Consultar informações sobre feiras e produtos.

Necessidade: Portal público para consultar feiras, feirantes e produtos disponíveis em Fortaleza.

Prioridade Média

Solução Proposta

Visão Geral

Um sistema web integrado e moderno que centraliza toda a gestão das feiras livres municipais, permitindo:

  • ✅ Cadastro digital de feirantes com histórico de alterações
  • ✅ Gestão de licenças com fluxo de aprovação automático
  • ✅ Controle de taxas com acompanhamento de pagamentos
  • ✅ Fiscalização facilitada com acesso em tempo real
  • ✅ Relatórios gerenciais para análise de desempenho
  • ✅ Portal público para consulta de feiras e feirantes

Características Principais

Tecnologia: Sistema web responsivo, acessível em desktop e dispositivos móveis

Autenticação: Autenticação segura para diferentes perfis de usuário

Rastreabilidade: Histórico completo de todas as alterações realizadas

Escalabilidade: Arquitetura preparada para crescimento futuro

Integrações: Preparado para integração com sistemas municipais existentes

Funcionalidades Principais

1️⃣ Gerenciar Cadastro de Feirantes

• Cadastrar Feirante - Registro de dados pessoais, tipo de produto e informações da barraca
• Atualizar Cadastro - Edição de informações cadastrais conforme necessário
• Consultar Feirantes - Busca com filtros por nome, produto, situação
• Remover/Inativar - Exclusão ou desativação de cadastros
• Histórico de Alterações - Rastreamento completo de mudanças realizadas

2️⃣ Gerenciar Feiras Livres

• Cadastrar Feiras - Criação de feiras com bairro, dia e horário
• Consultar Feiras - Acesso público a informações de feiras disponíveis
• Vincular Feirantes - Associação de feirantes autorizados a feiras específicas

3️⃣ Controle de Barracas

• Registrar Barraca - Cadastro de barracas vinculadas a feirante e feira

4️⃣ Gestão de Licenças (TPU)

• Solicitar Licença - Feirante pode solicitar autorização para atuar
• Aprovar/Reprovar - Análise e aprovação de cadastros pelo gestor
• Validar Autorização - Fiscal pode verificar se feirante está autorizado

5️⃣ Gestão de Taxas

• Registrar Pagamento - Lançamento de pagamentos de taxas
• Consultar Débitos - Verificação de taxas pendentes por feirante
• Validar Pagamento - Confirmação de regularização para participação

6️⃣ Relatórios e Análises

• Relatório de Arrecadação - Análise mensal de taxas coletadas
• Relatório de Feirantes Ativos - Listagem de feirantes por período e feira

7️⃣ Acesso e Segurança

• Autenticar Usuário - Login seguro com diferentes níveis de acesso
• Gerenciar Perfis de Acesso - Controle de permissões por papel

8️⃣ Fiscalização

• Consultar Feirantes Autorizados - Acesso rápido por feira
• Registrar Ocorrências - Documentação de irregularidades encontradas

Demonstração do Protótipo

Interface do Sistema

O sistema foi desenvolvido com uma interface moderna e intuitiva, seguindo padrões de usabilidade para garantir fácil adoção por todos os públicos.

Telas Principais

🖥️ Dashboard do Gestor

Visão geral com indicadores-chave: feirantes ativos, taxas arrecadadas, licenças pendentes

📋 Gestão de Feirantes

Lista com filtros, busca avançada, ações de edição e visualização de histórico

🎫 Gestão de Licenças

Fluxo de aprovação com validação de critérios e emissão de TPU

💻 Portal Público

Consulta de feiras, feirantes e produtos sem necessidade de autenticação

Protótipos de Alta Fidelidade

Foram desenvolvidos protótipos interativos que validam:

  • Fluxo de cadastro de feirantes com validações
  • Processo de aprovação de licenças
  • Geração de relatórios com gráficos
  • Responsividade em dispositivos móveis
Tecnologias Utilizadas: Frontend moderno (HTML5, CSS3, JavaScript), Backend robusto, Banco de dados relacional, API RESTful, Autenticação JWT

# Especificação de Requisitos Funcionais

## Caso de Uso (CDU) - Consultar feiras

## Histórico de Versões

| Data       | Versão | Descrição                               | Autor             |

## 1. Nome do Caso de Uso

Consultar feiras (público)

## 2. Objetivo

Permitir que qualquer cidadão consulte feiras disponíveis na cidade.

## 3. Tipo de Caso de Uso

Concreto

## 4. Atores

### 4.1 Primário

Cidadão

### 4.2 Secundário

Sistema

## 5. Precondições

* Acesso público ao portal de consulta.

## 6. Fluxo Principal

### P1. Usuário acessa página de feiras

> Sistema apresenta filtros básicos por bairro e dia.

### P2. Usuário consulta detalhes

> Exibe local e horários das feiras.

## 7. Fluxos Alternativos

### A1. Visualização em mapa

#### A1.1. Sistema mostra feiras em mapa interativo

## 8. Fluxos de Exceção

### E1. Falha no carregamento de mapa

#### E1.1. Sistema exibe lista alternativa

## 9. Pós-condições

* Cidadão obtém informação necessária para deslocamento.

## 10. Requisitos Não Funcionais

* Interface responsiva para dispositivos móveis.

## 11. Ponto de Extensão

Não se aplica

## 12. Frequência de Utilização

Alta

## 13. Interface Visual

### IV1. Página pública de feiras

> Lista, filtros e mapa.

## 14. Observações

* Informações públicas não devem expor dados sensíveis.
